**Regain** is a **Chromium-based** browser extension designed for effective **time management**.  

<br/>

## 📥 **Download the Extension**  
Download the latest release: [**Regain Latest Release**](https://github.com/roxylius/Regain/releases)  

<br/>

## 🚀 **Quick Installation**  
Follow these steps to install the extension:  

1. [Download the Latest Release (.zip)](https://github.com/roxylius/Regain/releases) and extract the file.  
2. Watch this [video tutorial](https://www.youtube.com/watch?v=oswjtLwCUqg) for a step-by-step guide on how to load the unpacked extension in any **Chromium-based browser** (e.g., Chrome, Edge, Brave).  

<br/>
